Onboarding course

Six short lessons that take you from “where is anything?” to shipping your first CRUD feature.

Mission

Become productive on this codebase: run it, trace any request end-to-end, and add features without breaking auth, permissions or data scope. MISSION.md

  1. 01The map: modules, layers and one requestFind the controller and the Vue page behind any screen.
  2. 02Login, tokens and refreshWhat a token is here, where it lives, and how the UI survives expiry.
  3. 03Permissions: menus, buttons, codesMake a button appear — and be enforced — for exactly the right role.
  4. 04Data scope: who sees which rowsPredict the SQL filter for any user and opt your queries in.
  5. 05Your first CRUD featureThe eleven touch-points, in order, and the framework magic behind them.
  6. 06Reuse the platform servicesDictionaries, params, files, logs, jobs, WebSocket — pick the right tool.

How to use these

Do one lesson per sitting (~10 minutes). Answer the practice questions before peeking — the struggle is what makes it stick. Come back a day or two later and redo the practice of the previous lesson before starting the next one; your first-try score is remembered in this browser and shown above.

The long-form docs are in docs/; the lessons point into them.

Stuck?Ask your agent (Claude) anything — “explain the refresh flow again”, “quiz me on data scope”, “walk me through SysRoleServiceImpl”. It's your teacher for this course and can read the code with you.
