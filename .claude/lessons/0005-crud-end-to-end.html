What BaseEntity gives you for free

Extend BaseEntity and these columns manage themselves:

ColumnMechanismEffect
creator, create_time, updater, update_time, org_idFieldMetaObjectHandler (auto-fill)set from SecurityUser + now on insert/update
deleted@TableLogicremoveById becomes UPDATE … SET deleted=1; reads add deleted=0
version@Version + OptimisticLockerInnerInterceptorupdateById adds WHERE version=? and bumps it

MyBatis-Plus docs: logic delete, auto-fill, optimistic lock.

And BaseServiceImpl gives you getPage(query) (paging + order/asc), dataScopeWrapper and getDataScope. Business errors: throw new ServerException("…") → {"code":500,"msg":"…"} → red toast.

The frontend in ten lines

const state: IHooksOptions = reactive({
  dataListUrl: '/biz/product/page',   // GET ?page&limit&order&asc&…queryForm
  deleteUrl: '/biz/product',          // DELETE, body = [ids]
  queryForm: { name: '', status: '' }
})
const { getDataList, sizeChangeHandle, currentChangeHandle,
        selectionChangeHandle, deleteBatchHandle, reset } = useCrud(state)

useCrud (src/hooks/index.ts) loads on mount, expects {list, total} back (PageResult), and confirms before deleting. The dialog component exposes init(id?) and emits refreshDataList.

Practice

1. Order the work for a new “Products” screen so that each step can be tested as you go.

  1. DBCreate biz_product with the standard columns
  2. BEEntity + DAO extending BaseEntity / BaseDao
  3. BEQuery, VO and Service (with dataScopeWrapper)
  4. BEController with @PreAuthorize codes; test in Swagger
  5. DBsys_menu rows: page url + button codes
  6. FEAPI file, list page and add/edit dialog with v-auth
  7. BEGrant to a role; verify as a non-admin user
Bottom-up keeps each layer testable: Swagger proves the API before any Vue exists, and the menu must exist before the page can be routed.

2. productService.removeById(5) — what actually happens in the database?

@TableLogic on BaseEntity.deleted plus logic-delete-value: 1 in application.yml turns deletes into updates: UPDATE biz_product SET deleted=1 WHERE id=5 AND deleted=0. The row stays; every MyBatis-Plus read adds deleted=0.

3. On insert, where do creator, createTime and orgId get their values?

insertFill reads SecurityUser.getUser(). Fields must be marked @TableField(fill = …) — BaseEntity does it for you; add it yourself for orgId.

4. Two admins open the same product. Both click Save; the second save changes nothing and no error appears. Why?

updateById adds AND version=<old>; the first save bumped it. MyBatis-Plus reports 0 rows — and the service doesn't check the return value. Consider throwing a ServerException when it returns false.

5. You added views/biz/product/index.vue, but clicking the menu shows 404. Most likely?

generateRoutes looks up /src/views/${url}.vue; the url must be biz/product/index (no leading slash, no .vue). Unmatched paths hit the catch-all /404 route.
Recall: what JSON shape must /biz/product/page return for useCrud to fill the table and pager?

{"code":0, "data": {"list": [...], "total": n}} — i.e. Result.ok(new PageResult<>(list, total)).
