Glossary

The project's vocabulary. Lessons and docs use these terms exactly as defined here.

Identity & sessions

Access token
Random 32-char UUID issued at login; a key into Redis (sys:token:<token>) holding the user's UserDetail. Lives 8 h. Sent as raw Authorization header or ?access_token=. Not a JWT.TokenUtils · TokenStoreCache · sys_user_token
Refresh token
Second UUID, valid 14 days, stored only in sys_user_token. Exchanged at POST /sys/auth/token for a new access token; also reloads permissions.SysUserTokenServiceImpl.refreshToken
UserDetail
The cached logged-in user: profile + authoritySet (permission codes and ROLE_*) + dataScopeList. Obtain with SecurityUser.getUser().maku-framework/…/security/user/UserDetail.java
Super admin
sys_user.super_admin = 1. Gets every permission code found in any @PreAuthorize, sees all menus and all rows. Seeded user admin/admin.
Authentication provider
One login method plugged into the ProviderManager: password (Dao), mobile SMS code, third-party (JustAuth).maku-boot-system/…/security/config/SecurityConfig.java
auth.yml / ignore_urls
Per-module list of URLs that skip authentication. All classpath*:auth.yml files are merged.PermitResource
SM2 / SM3
Chinese national crypto standards. SM2 (public-key) encrypts the password in the browser for transport; SM3 (hash) stores it in sys_user.password, unsalted.smCrypto.ts · Sm2Util · Sm3PasswordEncoder
Member
An end-user account in member_user (maku-module-member) — separate from system users (sys_user) who operate the admin UI.

Authorization

Permission code (authority)
String like sys:post:save (module:resource:action). Must match across @PreAuthorize, sys_menu.authority and v-auth.
Menu
Row in sys_menu. type 0 = page (its url maps to src/views/<url>.vue); type 1 = button (its authority holds comma-separated codes); type 2 = API. open_style 0 internal / 1 new window.
Role / role code
sys_role; grants menus via sys_role_menu and has a data scope. Its role_code becomes authority ROLE_<code>.
Data scope
Row-level visibility set per role: 0 ALL, 1 ORG_AND_CHILD, 2 ORG_ONLY, 3 SELF, 4 CUSTOM. Multiple roles → min() (broadest) wins. Applied only where a service opts in.DataScopeEnum · BaseServiceImpl.getDataScope · DataScopeInnerInterceptor
Org / Post
sys_org: organisation tree (by pid), basis for data scope. sys_post: job title, many-to-many with users.
v-auth
Vue directive that removes an element when the user lacks the code. Cosmetic only.src/utils/directive/auth.ts

Persistence

BaseEntity / BaseDao / BaseServiceImpl
Superclasses every feature extends: standard columns; MyBatis-Plus BaseMapper; ServiceImpl + getPage, dataScopeWrapper, getDataScope.maku-framework/…/mybatis
Logic delete
deleted column; deletes become UPDATE … deleted=1, MP reads filter deleted=0. Hand-written XML must filter it manually.
Optimistic lock
version column; updateById only succeeds if the version is unchanged.
Auto-fill
FieldMetaObjectHandler sets creator, create_time, updater, update_time, org_id, version, deleted from the current user and clock.
Entity / VO / Query
Entity = table row. VO = API request/response body. Query = list filters + page, limit, order, asc (extends Query). Converted with Hutool BeanUtil.

API contract

Result
Response envelope {code, msg, data}. code 0 = success; 400 refresh invalid; 401 not logged in; 403 forbidden; 500 error. HTTP status is 200 regardless.
PageResult
{list, total} — what paged endpoints put in data; what useCrud expects.
ServerException
Throw for business errors; becomes Result.error(code, msg) and a red toast in the UI.

Platform services

Dictionary (dict type / dict data)
Named list of value→label pairs (sys_dict_type, sys_dict_data), or the result of a SQL query (source SQL). Loaded once by the UI.
@Trans
VO field annotation that fills a label field on output: DICTIONARY (value→label) or SIMPLE (id→another entity's field).maku-framework/…/common/trans
Params
Runtime key/value settings in sys_params, Redis-cached, read via SysParamsService.
@OperateLog
Controller annotation recording an audit entry to sys_log_operate (via Redis queue sys:log).
Schedule job
schedule_job row naming a Spring bean + method + cron; executed by Quartz, logged to schedule_job_log.
StorageService / SmsApi / StorageApi
Vendor-neutral file storage and SMS. *Api interfaces live in maku-boot-api for use from other modules.

Frontend

generateRoutes
Turns the menu tree from GET /sys/menu/nav into Vue Router routes at runtime.src/router/index.ts
useCrud
Composable for list pages: paging, sorting, selection, delete, export, reset.src/hooks/index.ts
Ma* components
Global components: ma-dict-*, ma-upload-*, ma-org-*, ma-user-*, ma-editor…src/components
