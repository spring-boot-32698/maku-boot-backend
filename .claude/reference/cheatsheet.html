Auth flows

LOGIN   FE sm2Encrypt(pwd) → POST /sys/auth/login → captcha? → AuthenticationManager
        → createToken (sys_user_token upsert) → Redis sys:token:<at> = UserDetail (8h)
        → FE localStorage maToken/maRefreshToken → /sys/user/info, /sys/menu/authority,
          /sys/dict/type/all, /sys/menu/nav → generateRoutes
REQUEST Authorization: <at> → AuthenticationTokenFilter → Redis → SecurityContext
        → @PreAuthorize → service → MyBatis-Plus (DataScope→Pagination→OptLock→BlockAttack)
EXPIRY  code 401 → POST /sys/auth/token?refreshToken= → new at (perms reloaded) → replay
        code 400 → re-login
LOGOUT  POST /sys/auth/logout → del Redis key, expire DB row, login log
ROLE/USER EDIT → updateCacheAuthByRoleId/UserId → rebuild online users' Redis UserDetail
