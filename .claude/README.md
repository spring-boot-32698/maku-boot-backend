# .claude — onboarding workspace for maku-boot + maku-admin

Start here → open `lessons/index.html` in a browser.

| Path | What |
|---|---|
| `docs/` | Markdown documentation: tech stack, architecture, business flows, frontend, database, setup, feature recipe, gotchas. Start at `docs/README.md`. |
| `lessons/` | Short interactive HTML lessons (≈10 min each) with self-checking practice. |
| `reference/` | Printable quick reference: `glossary.html`, `cheatsheet.html`. |
| `assets/` | Shared stylesheet + quiz widget used by every lesson. |
| `MISSION.md` | Why this course exists and what "done" looks like. |
| `RESOURCES.md` | Trusted sources (code, official docs) and where to ask questions. |
| `NOTES.md` | Teaching notes / learner preferences. |
| `k8s/` | **Second course: Kubernetes & Helm with maku.** Start at `k8s/lessons/index.html`. Chart: `deploy/helm/maku`, guide: `deploy/helm/README.md`. |
| `learning-records/` | Created as the learner demonstrates understanding (none yet). |

All content was written from the source code on 2026-10-11. When the code changes, the code wins — update the docs.
